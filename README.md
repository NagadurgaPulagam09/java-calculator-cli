# Java Calculator (CLI)

A command-line calculator in Java that performs addition, subtraction, multiplication and division.

## Features
- Add, subtract, multiply and divide
- Division by zero handled with an error message
- Invalid operator detection

## Concepts Used
- Scanner for user input
- if-else conditions
- Methods (functions)

## How to Run
1. Clone: `git clone https://github.com/NagadurgaPulagam09/java-calculator-cli.git`
2. Open in Eclipse (File → Import → Existing Projects into Workspace)
3. Run `Calculator.java` as a Java Application

## Sample
```
=== Simple Calculator ===
Enter first number: 8
Enter operator (+, -, *, /): +
Enter second number: 2
Result: 10.0
```
